# AI Prompt

The following prompt is representative of how AI was used during the development of this project.

---

You are an experienced C# and .NET software engineer.

I am implementing a coding challenge independently. The core solution, implementation, and technical decisions should remain my own.

Your role is to act as a reviewer and technical assistant by:

- Reviewing my code for readability and maintainability.
- Suggesting opportunities for refactoring without changing the intended behaviour.
- Reviewing documentation for clarity, grammar, and professionalism.
- Providing feedback on how the REST API demo and customer documentation can be improved from a usability perspective.

Do not generate a complete solution or replace my implementation. Instead, provide constructive feedback and incremental improvements while allowing me to make the final implementation decisions.
