# AI Usage Declaration

This project was completed primarily through my own work. During development, I used ChatGPT in a limited capacity as a supplementary tool to support my learning and improve productivity. AI was not used to generate the complete solution or make implementation decisions on my behalf.

The use of AI was limited to the following:

- Clarifying parts of the assignment requirements where additional interpretation was helpful.
- Explaining C# and .NET language features or syntax when I needed clarification.
- Assisting with diagnosing Visual Studio build and environment-related issues, such as build errors, project configuration, and troubleshooting.
- Identifying occasional syntax or formatting mistakes during development.
- Proofreading project documentation and improving grammar, readability, and overall presentation.

The overall solution design, decoding algorithm, implementation, project structure, testing, debugging of the application logic, and all final technical decisions were completed by me. Any suggestions provided by the AI were reviewed, validated, and adapted where appropriate before being incorporated into the project.
