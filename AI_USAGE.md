# AI Usage

This project was implemented by me. ChatGPT was used as a supplementary development assistant to improve productivity and support the development process. It was not used to generate the complete solution or replace my implementation.

AI assistance was limited to:

- Clarifying parts of the assignment where additional interpretation was helpful.
- Explaining C# and .NET concepts when clarification was needed.
- Assisting with Visual Studio build, configuration, and environment-related troubleshooting.
- Identifying occasional syntax or formatting issues.
- Reviewing documentation for grammar, readability, and overall presentation.

The overall solution design, decoding algorithm, implementation, project structure, application logic, testing strategy, debugging of the solution, and all final technical decisions were completed by me. Any suggestions provided by the AI were reviewed, validated, and adapted before being incorporated into the project.
